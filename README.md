## 先说清楚：KVM VPS 到底是什么，为什么值得买

KVM（Kernel-based Virtual Machine）是 Linux 内核自带的全虚拟化方案。和早期 VPS 常见的 OpenVZ 容器虚拟化不同，KVM 给每个用户分配的是真正独立的虚拟机，拥有独立内核、独立资源、独立 IP，可以装 Windows，也能跑 Docker、自定义内核、VPN 这类需要系统级权限的东西。

对实际使用来说，KVM 的几个关键差别在于：

- **资源不被邻居偷走**：CPU、内存是独立分配的，同一台物理机上其他用户负载高的时候，你的 VPS 不会跟着卡。
- **完整 root 权限**：可以做任何一台独立服务器能做的事，包括改内核、装特殊模块。
- **支持 Windows 和自定义 ISO**：OpenVZ 做不到这一点，KVM 可以。
- **超售难度大**：这也是为什么同配置下 KVM 通常比 OpenVZ 贵一些，但稳定性更好。

搬瓦工早年是靠 OpenVZ 超售套餐起家的，2018 年之后逐步淘汰 OpenVZ，目前主推的全部是 KVM 架构。所以如果你现在去搬瓦工买 VPS，默认就是 KVM，不用再纠结架构选择的问题。
